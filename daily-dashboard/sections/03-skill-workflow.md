# 區塊 3：🛠️ 建立 Skill 的工作流程

**目標**：每天輪播一個「如何建立 Claude / Claude Code skill」的步驟或技巧，逐步把使用者與團隊培養成會自建 skill 的人。長期累積成內部 skill 開發手冊。

## 輪播主題（每天一個，循環）

1. **什麼是 skill**：一個資料夾 + `SKILL.md`（YAML frontmatter 的 `name` + `description` + 內容）。description 寫清楚「何時用」，Claude 才會在對的時機自動叫它。
2. **挑選好的 skill 題材**：找「重複做、步驟固定、容易做錯」的工作流程 —— 這種最值得變 skill。
3. **寫好 description**：描述要包含觸發情境與關鍵字，這是 Claude 決定是否載入的唯一依據。
4. **結構化內容**：把流程拆成清楚步驟、附範例、列出降級/錯誤處理。
5. **引用資源**：把長參考、範本、腳本放進 skill 資料夾的子檔，SKILL.md 用相對路徑引用，保持主檔精簡。
6. **測試 skill**：手動觸發跑一遍，確認 Claude 有照步驟做、輸出符合預期。
7. **迭代**：用真實任務跑，發現漏洞就回頭補 SKILL.md，把「踩過的坑」寫成規則。
8. **分享與重用**：把通用 skill 放進共用 repo 的 `.claude/skills/`，全團隊受益。

## 做法

依「當天是這個月第幾天 mod 主題數」選出今天的主題，輸出：
- 📌 今日主題標題
- 2-3 句說明
- 💡 一個可以馬上套用在頭盔王業務上的小範例（例如把每日對帳、補貨提醒做成 skill）

## 進階

若使用者當天提到某個重複性工作，可即時建議「這個適合做成 skill」並給出骨架。
