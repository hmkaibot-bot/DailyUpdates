# 區塊 2：🚀 生產力建議（個人 + 公司）

**目標**：每天給 1 個「個人生產力」+ 1 個「公司/團隊生產力」建議，必須具體、可在當天或本週執行。

## 做法

不要給通用心靈雞湯。建議要**長在當天的真實 context 上**：

1. 參考當日其他區塊：
   - 區塊 4 的停滯工作 → 「今天先清掉卡了 N 天的 PR #X」
   - 區塊 5 的生意數據 → 「零售轉換率掉了，建議檢查 A」
   - 區塊 1 的熱門工具 → 「可以引入 X 工具自動化 Y 流程」
2. 個人建議聚焦：時間管理、聚焦深度工作、減少 context switch、用 AI/自動化省時。
3. 公司建議聚焦：流程自動化、團隊協作、減少重工、把重複工作變成 skill / n8n workflow。

## 輸出格式

- 👤 **個人**：一句建議 + 為什麼（連到當日 context）
- 🏢 **公司**：一句建議 + 預期效益

## 原則

每天最多 2 條，寧缺勿濫。若某天沒有有意義的建議，就說「今日無特別建議，維持節奏」。
