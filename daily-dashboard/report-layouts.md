# 各報告版面（reports[]）

一次 run 產生多份，數字**只算一次**再組裝。每份對應 config `delivery.reports[]` 一項。
所有數字沿用各 section 已定義嘅算法（營收=最後完整日、賣車淨利=毛利×0.9、保險=保費×15% 等）。

---

= 現有完整版（見 `slack-template.md`）：集團生意四線 + 月目標追數 + 集團總 GP + 現金流 + 庫存 + 例外 + 停滯 + GitHub + 社群 + 生產力 + Skill。**公司級 block（GP/GitHub/社群/生產力/Skill）只喺呢度出。**

## 組裝規則
- **部組頻道只出自己嘅數**，唔好夾雜其他線或集團 GP。
- 每份最後一行 `:point_right: 今日：…` = 該部組今日行動。
- 任一 block 資料失敗 → 標「⚠️ 今日無法取得」，該份其餘照出；任一頻道發送失敗 → fallback DM，其餘頻道照發。
- 首次上線用 `send_mode: draft` 發草稿畀老闆驗收。
