# Slack 訊息範本

組裝最終 Slack 訊息時使用此格式（繁體中文、Slack markdown）。每區塊精簡，整體目標：**30 秒看完，知道今天該做什麼**。

```
:sunny: *頭盔王 Daily Dashboard* — {YYYY-MM-DD (週X)}

*🔥 GitHub 熱門項目*
1. <repo-url|repo 名稱> — 一句話用途　💡 關聯
2. ...

*🚀 生產力建議*
👤 個人：...
🏢 公司：...

*🛠️ 今日 Skill 工作流程*
📌 {今日主題}
{2-3 句說明 + 一個頭盔王應用範例}

*⏳ 停滯工作提醒*（涵蓋：{repos}）
• #123 標題 — 停滯 N 天 → 下一步建議
• ...

*🪖 集團生意*（資料截至 {last_complete_day} ｜ 本月 {elapsed}/{days_in_month} 日，應達 {pace%}）
*昨日* ｜ 零售 $X（N單）▲▼前日/上週同日　車房 $X（N張）▲▼前日/上週同日
*月目標追數（MTD / 目標 達成% ｜ 距標 ｜ 餘{n}日需/日）*
• 零售(營)：$X / $1.5M {%} ｜ 距 $X ｜ $X/日
• 車房(營)：$X / $400k {%} ｜ 距 $X ｜ $X/日
• 賣車(純利)：$X / $250k {%} ｜ 距 $X ｜ $X/日（成交 {台}｜開單 pipeline $X｜預留 {n}）
• 租車(純利)：$X / $20k {%} ｜ 距 $X ｜ $X/日（使用率 {%}/5架）
*💰 集團總利潤(MTD,估)*：$XXX,XXX　_零售/車房為毛利率估算(DB無COGS)_
*營運* ｜ 今日預約 M ｜ 未來預約 K
👉 {跨線洞察：哪條最落後、最該追}

*💬 社群熱門*
🤖 AI：{2-3 條當週話題} <url|來源>
🏍️ 電單車：{2-3 條當週話題} <url|來源>
💡 關聯：{一句對生意的關聯}

—
_由 daily-dashboard skill 自動產生 · {time}_
```

## 規則

- 任何區塊抓取失敗：保留標題 + 一行 `⚠️ 今日無法取得（原因）`，不要整份中斷。
- 被關閉的區塊（config `enabled: false`）：整段略過。
- 訊息開頭若有系統提醒（如找不到頻道、改發 DM），放在第一行。
- 數字加千分位；金額標幣別（HKD）。
- 連結用 Slack 格式 `<url|文字>`，不要把敏感資訊放進 url query。
