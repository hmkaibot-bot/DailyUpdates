# Slack 訊息範本（總則）

> **各報告版面（管理精簡版 / 零售 / 賣車 / 車房）以 `daily-dashboard/report-layouts.md` 為準。**
> 本檔只保留通用規則。管理版已改為**每日精簡前頁 + 逢星期一週報**（見 report-layouts.md ①）。

## 通用規則
- 目標：**管理版 30 秒睇完知重點；部組版睇自己線 + 今日行動**。
- 一次 run **查一次數**，組多份，各頻道**數字必一致**。
- **集團總 GP 一行必填**，不可留空（計法見 `sections/05-helmet-king.md`）。
- 營收/追數一律報**最後完整日**；今日未結算不計。賣車淨利 = 毛利 × 0.9（減 10% 佣）。
- 例外區**只列非零項**；全數正常寫「✅ 今日無異常」。
- 任何 block 抓取失敗：保留標題 + 一行 `⚠️ 今日無法取得（原因）`，不中斷。
- 部組頻道**只出自己線**，唔夾雜其他線/集團 GP；公司級 block（GP/GitHub/社群/生產力/Skill）只出 management。
- 任一頻道發送失敗 → fallback DM 給本人，其餘頻道照發。
- 數字加千分位；金額標 HKD；連結用 `<url|文字>`，勿放敏感 query。
- 首次上線用 `send_mode: draft` 發草稿驗收。
