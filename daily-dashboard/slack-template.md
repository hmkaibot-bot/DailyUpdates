# Slack 訊息範本

組裝最終 Slack 訊息時使用此格式（繁體中文、Slack markdown）。每區塊精簡，整體目標：**30 秒看完，知道今天該做什麼**。

```
:sunny: *頭盔王 Daily Dashboard* — {YYYY-MM-DD (週X)}

*🔥 GitHub 熱門項目*
1. <repo-url|repo 名稱> — 一句話用途　💡 關聯
2. ...

*🚀 生產力建議*
👤 個人：...
🏢 公司：...

*🛠️ 今日 Skill 工作流程*
📌 {今日主題}
{2-3 句說明 + 一個頭盔王應用範例}

*⏳ 停滯工作提醒*（涵蓋：{repos}）
• #123 標題 — 停滯 N 天 → 下一步建議
• ...

*🪖 頭盔王生意報表*（資料截至 {last_complete_day}）
*昨日* ｜ 零售 $X（N 單）▲/▼前日 ▲/▼上週同日　車房 $X（N 張）▲/▼前日 ▲/▼上週同日
*本月至今* ({month_start}→{last_complete_day}) ｜ 零售 $X（N 單）▲/▼上月同期　車房 $X（N 張）▲/▼上月同期
*營運* ｜ 今日預約 M ｜ 未來預約 K ｜（今日進行中 $Y _未結算_）
*🏍️ 賣車* ｜ 本月成交 {台} ｜ 已實現利潤 ${...} ｜ 本月開單 ${...} ｜ 客人預留 {n}
*🛵 租車* ｜ MTD ${...}（N單）｜ 車隊使用率 {%}（5架）｜ 今日取/還 A/B ｜ 押金在手 ${...}
👉 {一句洞察}

*💬 社群熱門*
🤖 AI：{2-3 條當週話題} <url|來源>
🏍️ 電單車：{2-3 條當週話題} <url|來源>
💡 關聯：{一句對生意的關聯}

—
_由 daily-dashboard skill 自動產生 · {time}_
```

## 規則

- 任何區塊抓取失敗：保留標題 + 一行 `⚠️ 今日無法取得（原因）`，不要整份中斷。
- 被關閉的區塊（config `enabled: false`）：整段略過。
- 訊息開頭若有系統提醒（如找不到頻道、改發 DM），放在第一行。
- 數字加千分位；金額標幣別（HKD）。
- 連結用 Slack 格式 `<url|文字>`，不要把敏感資訊放進 url query。
